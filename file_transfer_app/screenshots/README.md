# File Transfer Application - Screenshots (JPG Format)

This directory contains JPG screenshots of the File Transfer Application in action.

## Screenshots Included

1. **server_startup.jpg** - Server initialization and listening
2. **client_connection.jpg** - Client connecting to server
3. **successful_transfer.jpg** - Successful file download progress
4. **multiple_clients.jpg** - Server handling multiple concurrent clients
5. **error_handling.jpg** - Error message for non-existent file
6. **large_file_transfer.jpg** - Progress during large file transfer
7. **directory_structure.jpg** - Final directory structure after execution

## How to View

Open any JPG file with your default image viewer or a web browser.

## Description of Each Screenshot

### 1. server_startup.jpg
Shows the server starting up and listening on localhost:5000 with the serving directory initialized.

### 2. client_connection.jpg
Displays the client successfully connecting to the server and showing the interactive menu.

### 3. successful_transfer.jpg
Demonstrates a successful small file transfer with progress tracking showing 100% completion.

### 4. multiple_clients.jpg
Shows the server console handling 3 simultaneous client connections downloading different files.

### 5. error_handling.jpg
Illustrates the client receiving an error message when requesting a non-existent file.

### 6. large_file_transfer.jpg
Shows progress tracking for a larger file transfer (10 MB) with multiple progress updates.

### 7. directory_structure.jpg
Displays the complete directory structure after execution with all generated files and folders.
